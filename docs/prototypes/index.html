POC 靶场验证 · 前端呈现 — 三个原型

已按项目「纯白轻线」主题（antd 6 + Tailwind + lucide，绿色主色，发丝线边框，1rem 圆角，胶囊标签）重做 · 对应 Tier 3b 靶场验证流水线

方案 A · 轻量徽标型改动最小

发现详情「产物」tab 内：顶部绿色主按钮「发起靶场验证」+ poc-verify 产物卡（verdict 徽标、环境信息行、日志内联）。不新增页面与卡片。

适合：验证作为产物链一环，运营看产物中心即可。约 1 个组件改动。

方案 B · 验证状态卡 + 流程时间线信息最完整

发现详情页独立「靶场验证」卡片：左侧环境事实（镜像 / TARGET / 隔离边界 / 强制重跑），右侧六步流水线时间线，底部 verdict 大横幅 + 自动验证提示。

适合：向使用者解释「AI 参与了什么、边界在哪」；单发现视角体验最好。约 2 个组件改动。

方案 C · 独立验证控制台改动最大

哨兵下新增一级 tab：统计卡 + 验证任务表格（verdict 徽标、进度条、批量重跑、按严重度补齐）+ 内存破坏类自动分流到差分复现。

适合：验证量大、统一运营 Tier 3a/3b；涉及新路由 + 后端列表 API。
